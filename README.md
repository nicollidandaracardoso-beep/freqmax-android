# FreqMax Android App

Aplicativo Android desenvolvido em Java para cadastro de atletas e cálculo de frequência cardíaca máxima (FCM).

## Sobre o projeto

O FreqMax é um aplicativo desenvolvido com o objetivo de aplicar conceitos de programação orientada a objetos e desenvolvimento Android, permitindo cadastrar atletas e calcular sua frequência cardíaca máxima com base na idade.

## Funcionalidades

- Cadastro de atletas
- Cálculo da frequência cardíaca máxima
- Organização dos atletas por FCM
- Interface Android com campos de entrada e lista de dados

## Tecnologias utilizadas

- Java
- Android Studio
- XML
- Android SDK
- Programação Orientada a Objetos

## Conceitos aplicados

- Classes e objetos
- Construtores
- ArrayList
- Manipulação de listas
- Ordenação de dados
- Eventos de interface
